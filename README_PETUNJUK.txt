BAB 1 MATEMATIKA KELAS II SD/MI — AYO MEMBILANG SAMPAI DENGAN 50
Pendamping Akademik | 32 halaman interaktif

ISI BERKAS
- index.html : seluruh 32 halaman lengkap dalam satu berkas; navigasi, latihan, evaluasi.
- daftar_halaman.json : indeks nama tiap halaman untuk pengembangan.
- SUMBER_FOTO.txt : kredit foto dan sumber.

CARA MENCOBA
1. Buka index.html menggunakan Chrome, Edge, atau Firefox.
2. Klik 'Daftar Isi', tombol 'Sebelumnya' atau 'Berikutnya'.
3. Jawab latihan. Hasil halaman terakhir disimpan sementara melalui localStorage per peramban.
4. Foto membutuhkan koneksi internet karena menggunakan URL foto berlisensi Unsplash. Tidak ada gambar foto yang tersimpan di dalam ZIP. Bila offline, konten matematika tetap berfungsi.

CARA MENGUNGGAH KE GITHUB PAGES
1. Buat repositori khusus, misalnya matematika-kelas2.
2. Unggah index.html pada root repo atau folder bab-1.
3. Aktifkan GitHub Pages pada Settings > Pages, pilih branch main dan folder root.
4. URL akan mengikuti nama akun serta repositori GitHub Anda.

CARA MENAMPILKAN DI BLOGGER
- Buat Halaman Baru > Tampilan HTML; tanam iframe berikut (ganti URL di bawah dengan URL GitHub Pages milik Anda):
<iframe src="https://NAMA-USERNAME.github.io/NAMA-REPO/" title="Matematika Kelas II Bab 1" style="width:100%;height:850px;border:0;border-radius:14px" loading="lazy" allowfullscreen></iframe>
- Jangan menempelkan kode index.html penuh ke Blogger bila editor menghapus JavaScript.

CATATAN PENTING
- Materi dan kuis merupakan pengembangan orisinal Pendamping Akademik; tidak menyalin halaman buku pemerintah.
- Model puluhan-satuan adalah model hitung yang dibuat dengan CSS dan JavaScript untuk menjamin jumlah benda tepat. Foto asli adalah pendamping materi, bukan gambar hitung yang harus dihitung satu-satu.
